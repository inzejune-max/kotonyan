# Котонянь

Лендинг кэт-ситтера в Тбилиси. Статический сайт: `index.html`, `css/style.css`, `js/main.js`, фото в `img/`.

Два языка (RU/EN) переключаются на месте: русский текст лежит в HTML, английский в словаре `js/main.js`.

Локальный просмотр: любой статический сервер из корня, например `npx serve .`
