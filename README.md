# Котонянь

Лендинг кэт-ситтера в Тбилиси. Статический сайт на GitHub Pages: https://inzejune-max.github.io/kotonyan/

- Русская версия: `index.html` (адрес `/kotonyan/`)
- Английская версия: `en/index.html` (адрес `/kotonyan/en/`), собирается скриптом из `index.html` и словаря `i18n/en.json`

Правки: менять текст в `index.html` (RU) и в `i18n/en.json` (EN), затем `node build.js`, коммит и `git push` в `main`. Сайт обновляется через 1–2 минуты.

Локальный просмотр: любой статический сервер из корня, например `npx serve .`
